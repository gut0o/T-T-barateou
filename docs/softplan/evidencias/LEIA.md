# Evidências de novas execuções

Para gerar relatórios automaticamente, execute a partir da raiz:

```powershell
node scripts/ai-curator-portfolio.mjs "https://meli.la/UM_LINK_REAL" "https://meli.la/OUTRO_LINK_REAL"
```

O script salvará dois arquivos (JSON e Markdown) com a data da execução. Por padrão, esses arquivos **não contêm** links de afiliado, headers nem chaves de API. Ainda assim, revise os arquivos antes de enviá-los a terceiros. As respostas são estimativas qualitativas da IA e não medem vendas, cliques ou descontos históricos.
