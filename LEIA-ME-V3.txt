O QUE A V4 FAZ

📱 Eletrônicos
- Continua automático.
- Mantém a regra normal de 30 dias.

💪 Fitness
- Continua automático.
- Mantém a regra normal de 30 dias.

🌸 Perfumes
- Continua SEM descoberta automática.
- Usa somente links colocados por você em RESERVA PERFUMES.
- A lista vira circular.
- Depois que todos forem usados, o bot volta ao mais antigo quando ele completar 4 horas desde o último envio.
- Antes de cada novo envio o anúncio é aberto novamente, os dados são atualizados e um NOVO link meli.la é gerado/validado.
- Link inválido, oferta removida ou falha permanente é pulada/rejeitada.
- A regra especial de 4 horas vale SOMENTE para Perfumes.

COMO APLICAR

1. Extraia este ZIP na raiz do projeto.
2. Quando o Windows perguntar, escolha SUBSTITUIR os arquivos.
3. Rode o mesmo comando que você já usou na V3:

   node apply-perfumes-semi-auto-v3.mjs

4. Depois valide:

   node --check whatsapp/publish-queue.js
   node --check lib/tt-fallback-reserve-store.js
   node --check lib/tt-pending-publication-store.js
   node --check lib/tt-queue-admin-actions.js

Se os quatro comandos não mostrarem erro, rode:

   git --no-pager diff -- whatsapp/publish-queue.js lib/tt-fallback-reserve-store.js lib/tt-pending-publication-store.js lib/tt-queue-admin-actions.js

IMPORTANTE

- Não precisa criar variável nova: o padrão é 4 horas.

- Nenhum secret é alterado.
- Nenhuma sessão do WhatsApp é alterada.
- Este instalador não liga o PM2.
