node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"

Instalação na branch painel-web-v1:
1) Extraia o ZIP na raiz do projeto.
2) node --check api/admin.js
3) git status
4) git add admin api/admin.js
5) git commit -m "Adiciona painel web administrativo v1"
6) git push -u origin painel-web-v1
7) Configure as duas variáveis no Vercel.
8) Teste o preview antes de mergear.
